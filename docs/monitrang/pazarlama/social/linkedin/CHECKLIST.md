# LinkedIn Şirket Sayfası — Açılış Kontrol Listesi

Şirket adı net değilse bu checklist'i şirketleşme sonrasına erteleyin veya geçici olarak kişisel profilden duyuru yapın. Bkz. [../kurumsal-yapi-notu.md](../kurumsal-yapi-notu.md).

## Hesap oluşturma (LinkedIn arayüzü)

1. [ ] Kişisel LinkedIn → **For Business** → **Create a Company Page**
2. [ ] Sayfa türü: **Company** (kurumsal)
3. [ ] **Page name:** *(tüzel kişilik adı — şirketleşme sonrası)*  
   **Görünen ürün / tagline:** MonitraNG (`profil-metinleri.md`)
4. [ ] **LinkedIn public URL:** `/company/monitrang` (müsaitse)
5. [ ] **Website:** `https://www.monitrang.com`
6. [ ] **Industry:** *(karar — örn. Software Development)*
7. [ ] **Company size:** *(karar)*
8. [ ] **Page type:** Public Company veya Privately Held *(karar)*
9. [ ] Onay kutularını işaretle → **Create page**
