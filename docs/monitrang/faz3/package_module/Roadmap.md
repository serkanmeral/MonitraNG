# Package Module — Roadmap (Faz 3)

**Teklif:** §4.6 İş Paketleri Modülü — sürekli güncelleme  
**Klasör:** `docs/monitrang/faz3/package_module/`  
**Durum:** Planlama iskeleti  
**Son güncelleme:** 13 Temmuz 2026

---

## 1. Amaç

Mevcut İş Paketleri modülünün bugünkü ve gelecekteki Odak ihtiyaçlarına göre **sürekli güncellenmesi** (tek seferlik kurulum değil; dilimli geliştirme).

## 2. Kapsam özeti (tekliften)

| Alan | Madde |
|:---|:---|
| Analiz | Mevcut süreç + iyileştirme backlog |
| Tempo | Periyodik dilimler (toplantıda netleşir) |
| İçerik | İşlev, ekran, entegrasyon, rapor/DI çıktıları |
| Örnek uyum | Medya paketi, sunum, kontrol paneli, sevkiyat listesi vb. |
| Teslim | Sürüm notu + kabul |

## 3. Mevcut / yeni

| | Durum (kabaca) |
|:---|:---|
| İş paketi / medya / DI bağları | Odak’ta ürünleşmiş parçalar var |
| “Sürekli güncelleme” sözleşmesi | Süreç + backlog yönetimi **yeni çerçeve** |

## 4. Fazlar (taslak)

| Faz | Hedef |
|:---|:---|
| PKG-0 | Mevcut iş paketi envanteri + borç listesi |
| PKG-1 | Backlog öncelik modeli (P0/P1/P2) + dilim ritmi |
| PKG-2 | İlk iyileştirme dilimi (toplantı sonrası) |
| PKG-n | Sonraki dilimler → her biri `work.md` + MIGRATION satırı |

## 5. Bağımlılıklar

- DI, Reporting, sipariş/OC verisi (dilime göre)  
- [../MIGRATION.md](../MIGRATION.md)

## 6. Kabul (özet)

Her dilim: tanımlı kapsam, smoke, sürüm notu; tempo müşteri ile yazılı.
