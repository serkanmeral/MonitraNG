# API Documentation Overview

## Genel Bakış

MonitraNG platformu, RESTful API'ler aracılığıyla çeşitli servislere erişim sağlar.

## Servisler

### MngKeeper
Kimlik doğrulama ve kullanıcı yönetimi servisi.

### MngDataGateway
Dataset yönetimi ve veri sorgulama servisi.

### MngHub
Hub yönetimi servisi.

## API Dokümantasyonu

Her servis için detaylı API dokümantasyonu aşağıdaki bölümlerde bulunabilir:
- OpenAPI/Swagger JSON dosyaları
- Endpoint açıklamaları
- Request/Response örnekleri
