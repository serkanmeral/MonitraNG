# MngKeeper Technical Specs (API Referansı)

Test ekibinin kullandığı birincil API referansı. Tüm endpoint'ler, request/response alanları ve örnekler bu dokümanda tutulur.

## Durum

İçerik eklenecek. Endpoint listesi ve her bir istek alanı için detaylı açıklamalar (alan adı, tip, zorunlu/opsiyonel, açıklama, örnek değer) DOCUMENTATION_STANDARDS.md §3.6’ya göre buraya işlenecektir.

Geçici olarak Swagger UI kullanılabilir: `http://localhost:5001/api-docs` (veya gateway üzerinden ilgili path).
